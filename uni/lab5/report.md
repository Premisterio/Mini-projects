# Звіт з лабораторної роботи №6

## Тема
Створення адаптивної версії портфоліо-сайту з використанням Bootstrap 5.

## Мета
Оволодіти базовими принципами роботи з фреймворком Bootstrap 5: сітковою системою, готовими компонентами, утиліт-класами. Переробити макет з практичної роботи №3 у повністю адаптивний шаблон, що коректно відображається на моніторах, планшетах і смартфонах.

## Загальна Bootstrap-сітка макету

```
┌─────────────────────────────────────────────────────────┐
│ NAVBAR (navbar-expand-lg, sticky-top, container-fluid)  │
├─────────────────────────────────────────────────────────┤
│ HERO        container > row                              │
│   col-lg-7 — текст + CTA   │   col-lg-5 — фото-картка   │
├─────────────────────────────────────────────────────────┤
│ ABOUT       container > row                              │
│   col-lg-6 — опис          │   col-lg-6 — list-group    │
├─────────────────────────────────────────────────────────┤
│ SKILLS      container > row (bg-surface)                 │
│ col-md-6 col-lg-4 │ col-md-6 col-lg-4 │ col-md-6 col-lg-4│
│  Frontend         │  Backend          │  Tools          │
├─────────────────────────────────────────────────────────┤
│ VIDEO       container > row                              │
│   col-lg-9 — ratio-16x9 YouTube iframe                  │
├─────────────────────────────────────────────────────────┤
│ PROJECTS    container > row (bg-surface)                 │
│   3× col-md-6 col-lg-4 (card project-card)              │
├─────────────────────────────────────────────────────────┤
│ CONTACT     container > row                              │
│   col-lg-6 — form          │   col-lg-6 — посилання     │
├─────────────────────────────────────────────────────────┤
│ FOOTER (d-flex, flex-md-row)                             │
└─────────────────────────────────────────────────────────┘
```

### Брейкпоінти
- **< 768px (мобільний):** усі колонки вертикально (`col-12`); навбар згортається в гамбургер.
- **768–991px (планшет):** skills і projects по 2 в ряд (`col-md-6`).
- **≥ 992px (десктоп):** повна сітка, skills і projects по 3 в ряд, навбар розгорнутий.

## Особливості верстання

### Адаптивний підхід
Використано **mobile-first** підхід Bootstrap: класи без префікса (`col-12`) застосовуються для мобільних, а `col-md-*`, `col-lg-*` розширюють їх для більших екранів. Для горизонтальних відступів — утиліти `g-4`, `gap-2`, `py-5`. Усі сітки реалізовано через `container > row > col-*` без жодного власного `display: grid`.

### Фіксований навбар
`<nav class="navbar navbar-expand-lg sticky-top">` — навбар прилипає до верху сторінки при скролі. На екранах ≤991px колапсує через `navbar-toggler` у бургер-меню (вбудована JS-логіка Bootstrap).

### Адаптивне відео
YouTube-iframe обгорнутий у `<div class="ratio ratio-16x9">` — Bootstrap-утиліта, що зберігає пропорції 16:9 на будь-якій ширині екрана.

### Анімації (вибірково, з логікою)
Підключено бібліотеку **AOS** (Animate On Scroll). Анімовано **лише** контентні блоки, які мають "ефект появи":
- **Hero:** `fade-right` для тексту, `fade-left` для картки — створює відчуття "розльоту" контенту з центру.
- **Заголовки секцій:** `fade-up` — спливають знизу при скролі.
- **Skills (3 картки):** `zoom-in` із прогресивним `data-aos-delay` (0 → 150 → 300 ms) — каскадна поява.
- **Projects (3 картки):** `flip-up` із тим самим каскадом.
- **Contact:** `fade-right` для форми, `fade-left` для лінків.

Що **НЕ** анімовано: навбар, футер, заголовки усередині карток, текстові абзаци — щоб не перевантажувати око.

Окремо реалізовано постійну CSS-анімацію — пульсуючий індикатор `.dot` через `@keyframes pulse` (статус "Open to work").

### Готові компоненти Bootstrap
`.navbar`, `.btn`, `.card`, `.badge`, `.form-control`, `.list-group`, `.progress`, `.ratio`, `.container`, `.row`, `.col-*`, утиліти `.d-flex`, `.gap-*`, `.py-*`, `.g-*`, `.text-uppercase`.

## Висновки

У ході виконання лабораторної роботи опановано фреймворк Bootstrap 5, його сіткову систему та готові компоненти. Перевагами використання Bootstrap, виявленими у процесі роботи, є:
- **Швидкість розробки:** адаптивний навбар, ratio-контейнер, form-контролі, list-group — усе підключається класами без власного CSS.
- **Прогнозований адаптив:** mobile-first брейкпоінти (sm/md/lg/xl) одразу покривають усі типові пристрої — не потрібно вручну писати media queries для кожної секції.
- **Узгодженість компонентів:** усі картки, кнопки, форми мають єдиний baseline-стиль.

**Критичний аналіз:**
- Bootstrap "тягне" близько 200KB CSS, з яких реально використовується ~20%. Для продакшну варто кастомізувати збірку через SASS і виключити невикористані компоненти.
- Стандартні стилі Bootstrap довелось перевизначати під темну тему — це часткова втрата переваги "готового вигляду".
- AOS-анімації — окрема залежність (~15KB JS + CSS); для продакшну краще замінити на нативні `IntersectionObserver` + CSS-keyframes.

Загалом, мети досягнуто: сайт коректно відображається на десктопі, планшеті та смартфоні; усі обов'язкові елементи (адаптив, текст замість картинок, YouTube-відео, вибіркові анімації) реалізовано. Код пройшов валідацію W3C.
