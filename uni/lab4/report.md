## Короткий опис моделі

Модель складається з трьох вкладених елементів:
- **`.orbit`** — пунктирне коло, що візуалізує орбіту Місяця.
- **`.earth`** — Земля у центрі, обертається навколо власної осі (анімація `earth-rotation`, період 10 с).
- **`.moon-orbit`** — невидимий контейнер-обгортка, який обертається навколо центру Землі (анімація `moon-rotation`, період 6 с). До нього прив'язано `.moon` зі зсувом, завдяки чому Місяць рухається по колу навколо Землі.

Тло створене за допомогою `radial-gradient`, що імітує глибину космосу. Сама Земля та Місяць також виконані з радіальними градієнтами для імітації об'єму, а ефект "свічення" досягнуто за рахунок `box-shadow`.

## Фрагменти коду

### HTML (index.html)
```html
<div class="space">
    <div class="orbit">
        <div class="earth">
            <div class="moon-orbit">
                <div class="moon"></div>
            </div>
        </div>
    </div>
</div>
```

### CSS (style.css) — ключові фрагменти

**Орбіта та Земля:**
```css
.orbit {
    width: 400px;
    height: 400px;
    border: 1px dashed rgba(255, 255, 255, 0.3);
    border-radius: 50%;
}

.earth {
    width: 100px;
    height: 100px;
    background: radial-gradient(circle at 30% 30%, #4a90e2, #1a4d8f, #0d2a4f);
    border-radius: 50%;
    box-shadow: 0 0 30px rgba(74, 144, 226, 0.6);
    animation: earth-rotation 10s linear infinite;
}
```

**Місяць на орбіті:**
```css
.moon-orbit {
    width: 250px;
    height: 250px;
    position: absolute;
    animation: moon-rotation 6s linear infinite;
}

.moon {
    width: 30px;
    height: 30px;
    background: radial-gradient(circle at 30% 30%, #ffffff, #cccccc, #888888);
    border-radius: 50%;
    position: absolute;
    top: -15px;
    left: 50%;
    margin-left: -15px;
}
```

**Анімації:**
```css
@keyframes earth-rotation {
    from { transform: rotate(0deg); }
    to   { transform: rotate(360deg); }
}

@keyframes moon-rotation {
    from { transform: rotate(0deg); }
    to   { transform: rotate(360deg); }
}
```

## Висновки

У ході виконання лабораторної роботи було вивчено основи створення CSS3-анімацій. Засвоєно:
- використання правила `@keyframes` для опису кадрів анімації;
- властивість `animation` та її складові (тривалість, функція згладжування `linear`, нескінченне повторення `infinite`);
- техніку обертання об'єкта по орбіті через прив'язку дочірнього елемента до контейнера зі зсувом і застосування `transform: rotate()` до контейнера;
- використання `radial-gradient` та `box-shadow` для імітації об'ємних небесних тіл.

**Критичний аналіз:**
Реалізація є спрощеною та не враховує таких астрономічних особливостей, як еліптичність орбіти Місяця, нахил орбітальної площини та реальне співвідношення періодів обертання. Для більш реалістичної моделі можна використати `animation-timing-function: cubic-bezier()`, додати фази Місяця через `@keyframes` зі зміною `background`, а також 3D-перспективу через `transform: perspective()` та `rotateY()`.

Загалом, поставленої мети досягнуто: анімація працює у всіх сучасних браузерах і коректно відображає головну ідею — обертання Місяця навколо Землі.
